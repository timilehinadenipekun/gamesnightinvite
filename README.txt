TIMILEHIN'S GAME NIGHT — PINK ARCADE

1. Go to https://formspree.io and create a free form using the email where you want RSVPs.
2. Copy the form endpoint (looks like https://formspree.io/f/abcdefgh).
3. Open index.html in a text editor. Replace https://formspree.io/f/YOUR_FORM_ID with your endpoint.
4. Test an RSVP and verify that it reaches Formspree / your email. The form intentionally refuses to submit until the endpoint is replaced.
5. Host for free on GitHub Pages: create a public repository, upload index.html to the repository root, then Settings > Pages > Deploy from a branch > main / root. Wait for GitHub's live link.
6. Share that link on WhatsApp.

Privacy: the website only says McKernan and University Station; no private street address is published. Submitted names, attendance and dietary notes are handled by Formspree; review its privacy settings. The website has no public guest list.
